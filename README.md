# Circuit Arena Fut - Versão Final com Modo Público

## Como abrir no VS Code
1. Abra a pasta `circuit-arena-fut` no VS Code.
2. Clique com o botão direito no `index.html`.
3. Clique em `Open with Live Server`.

## Modo admin
Abra normalmente:
`index.html`

Você consegue:
- editar duplas
- lançar placares
- limpar placares
- limpar categoria
- usar modo telão
- usar modo limpo

## Modo público/travado
Abra assim:
`index.html?view=1`

Quem abrir nesse modo só consegue:
- trocar categoria
- navegar pela tabela
- usar modo telão/modo limpo

Não consegue:
- editar duplas
- editar placares
- limpar dados

## Importante
Se você publicar online, compartilhe o link com `?view=1` no final.
